## 可检索的男性外部照片

2026-10-28用户明确要求收录两页小红书照片，并要求以后生成新男生时按人物需要选用、不要总沿用之前三张。已收录[男性自拍照片与逐图索引](research-2026-10-28/xhs-male-selfies/index.md)：按脸部体量、眉眼鼻唇、整头发型、注视与表情检索，实际打开适配图片后取舍；“受限”记录只支持列明部分。

新男性选材不以“曾用过、曾成功”代替本次适配，不固定旧三张或相同分工组合，也不为轮换随机选脸。旧资料在适用时仍可用；在本次设计记录中写明来源编号与具体采用关系。收录只是外部观察资料更新，不自动扩展真人图片输入授权，也不将任何照片变成默认身份。

[男性发型、五官与穿搭补充](research-2026-10-28/male-hair-face-style/index.md)另存41张已看封面与逐条限制，重点检索短碎发、直前刘海、散碎刘海、卷曲及露额轮廓；三七分不再默认。这个数量包含梗图、拼图和受限样本，不等于41位可靠真人，选材须按具体用途和排除标记执行。

## 生成新人物前：从外部取材

### 看图型调研：扩大样本、减少无关操作

2026-10-28，用户要求：“多注意调研发型，五官长相，脸型，人物风格。看图片就可以，减少不必要的动作，加快效率看更多的图。”随后明确要求“记录skill”。这条适用于补充外部人物素材库的看图调研，不改动具体出图任务的身份、背景与服装要求。

- 以实际看图为主，优先批量浏览封面、连续加载及编号拼图，增加不同发型、脸部结构与人物风格的覆盖；不默认逐帖打开、读长文案或翻评论。确有重要结构看不清时，再看少量原尺寸图或详情。
- 发型观察覆盖分缝、刘海厚薄与落点、头顶/两侧/后脑体量、长度、层次、卷直、扎发与发尾方向；同时看其与脸型和眉眼的关系，不能只记“长发、短发、自然碎发”。
- 五官长相与脸型观察眉眼及眼睑、鼻唇、颊颌的相容关系；人物风格观察妆发、衣服体量、配饰、姿态与神态的整体组合，不用空泛风格标签代替可见细节。
- 来源、编号、图片与简短观察批量保存；按笔记和图片去重，标明同作者、遮挡、透视、妆造或低清限制。封面、原尺寸复查、详情和独立人物分开计数，访问或下载成功不等于已经看图。
- 新资料追加到现有素材库并保留旧资料，后续按当前角色需要自主选材；不把单个样本设成固定发型、五官或身份模板。调研和入库本身不触发人物生成。

女性自拍新增[61张女自拍封面与逐图索引](research-2026-10-28/xhs-female-selfies/index.md)（2026-10-28）：优先按当前需要检索整头发型、刘海、颊颌体量、五官与神态及穿搭组合；综合观察和仅妆发造型的范围分开标明，实际取舍见逐图记录。6张原尺寸复查仍属于这61张封面，不累加为新人物。

- 素材来源是用户本次提供的参考和已归档/新调研的外部图片。按当前年龄、性别呈现、脸型、气质与任务选看相应样本及其观察记录，不要求用户再次点名调用。
- 实际查看相关外部素材，确认其能支持的部分。妆容、转头、微笑、俯拍、低清和遮挡分别处理；AI明示、插画、搬运或来源未核验者保留标记，不当作可靠的人体实测。

- 男性人物或过度端正纠偏按[来源覆盖与输入分流](male-natural-presence.md)补看整头发型和完整神态。记录图片是仅观察还是实际传入；局部眼图不支持发型，低清图不支持眼睑唇缘细节。一般选材由助手完成，确有材料或访问缺口时才具体说明需要用户提供什么。
- 新人物不打开历史生成图库找灵感，不加载旧角色、认可图、失败图、眼部裁切或拼图充当新脸设计或比较素材；不能换名为版式、皮肤参考绕过边界。当前作品的编辑基准不属于新人物素材库。
- 旧提示词的人脸结构段同样不能作为新脸的循环模板。中性的排版和连续性要求可继续使用，但本次五官关系必须由相关外部观察与独立设计重新确定。

## 跨样本参考：让各部分属于同一张脸

允许从不同外部人物获取局部灵感，不要求一张参考包办整脸，也不按字面把眼、鼻、嘴剪贴在一起。

| 参考分工 | 需要协调的关系 |
| --- | --- |
| A的眼睛 | 采用眼裂、上下睑、眼头眼尾或注视状态中的适用关系；将眼宽、眼距、眉下空间、虹膜露出调整到本次脸宽和颧颊体量。 |
| B的鼻部 | 参考鼻根、鼻背、鼻头鼻翼的体量衔接；与中庭长度、眼间留白、嘴宽和侧面轮廓协调。 |
| C的唇形 | 参考唇峰、唇线、上下唇或嘴角；与鼻唇距离、下庭、下巴及讲话/微笑的口周牵动协调。 |
| 整体发型与神态 | 观察头顶两侧体量、发根走向与刘海落点，及注视、眼睑、眉颊口周的联动；调整到本次头形与脸部体量，不借用完整身份，不只加飞丝或歪头。 |
| 脸型、身体与状态 | 先确定本次整体骨相、年龄和面部体量，再对局部尺度作取舍；脸型、肩臂体量及服装松量分别观察。 |

只选本次确实需要的少量来源，不固定每次三个人或相同分工。不能把各器官各自理想化，也不把不同年龄、角度或妆造下的局部比例原样硬套。漂亮、协调与辨识度同时成立，不能用故意歪脸、统一缩眼或堆瑕疵代替自然组合。

在本次设计/生成记录中简短写明：实际来源或本地图路径 → 观察到的局部关系 → 本次采用方式 → 为整脸自然协调所作的调整。记录不是把参考人物的所有比例编码成身份，也不等于自动上传这些照片；默认仍转为文字，只有用户当次明确要求或授权结构／发型／状态图像输入时才按其范围执行；既有授权不重复询问，也不扩展到其他新人物。

## 验收与角色连续性的边界

- 新人物验收当前图及其裁切，对照生成前结构记录和实际外部观察；不调历史生成角色比较，不把当前输出拿去设计下一位人物。
- 同角色换装／身高比例：只引用已认可独立正脸作为身份条件；完整旧资产图只供结果核对，禁止作为底图、画布、编辑目标或最近图片输入。必须重新生成新资产图。
- 本任务正脸经用户认可或被明确指定继续，并且已要求资产板时，可以作为本角色身份参考展开。未认可草稿不能因助手自评自动锁定，失败脸不能作为新脸的锚点。
- 未经用户认可的草稿不能被升级为定脸；服装／比例修订也不能把该完整草稿当底图修改。先定位已有独立认可正脸，没有就说明身份缺口，不用失败脸凑数。
- 新人物外部照片默认只转成文字；明确保留本人或授权结构／发型／状态图像输入时才按范围传入。换装的服装图须标明仅衣服／配件，排除模特身份；认可正脸作为同角色身份参考，不能与完整资产图编辑混称。
- 长相设计失败回到外部来源；同角色衣服／比例失败仍从正确独立正脸和本次要求重新生成，禁止编辑失败整版。其他类型修订按用户当次范围处理，不借其名义绕过本流程。

这些规则同时保留“新人物不得复用旧脸”和“同角色可引用独立认可正脸”两条边界，并按用户最新要求禁止换装／比例的旧图底图编辑。历史输入链和评价保留，不能用历史编辑案例恢复旧换装方法。技能记录继续遵守“存档”或直接更新技能的授权边界。
