# 原创脸设计、验收与同任务保形

2026-10-27，用户直接要求修改技能：解决新人物模板化并保留同角色已认可长相；随后明确要求资产图交付后追加换装／身高选项，该过程只能重新生成，禁止把图片当底图修改。当前以这里的分流为准，历史评价和研究资料保留；早先“衣服问题局部编辑”不再作为换装／比例流程执行。

## 1. 先判断是在设计谁

| 请求 | 输入与行动 | 不允许的替代 |
| --- | --- | --- |
| 设计新的原创人物 | 实际选看本次用户参考及外部调研；重新写结构设计记录；默认文字生成人脸 | 用旧生成角色、旧认可脸或失败脸作为新角色的灵感、身份参考或比较基准 |
| 同一角色换装、裙摆、穿搭配件、身高或身材比例 | 引用已认可独立正脸及本次服装／身高条件，生成一张新资产图 | 把旧资产图作编辑底图、局部重绘、拉伸或拼贴；或无身份参考地重抽新脸 |
| 将本任务已认可正脸展开成资产板 | 在用户已要求资产板的范围内，以这张正脸作为该角色的身份参考，核对各视图 | 重新纯文字生成整版，或把这张脸用来设计下一位新人物 |
| 用户否定长相、要求另造人物 | 取消该失败脸作为身份基准，返回外部样本和独立结构设计 | 一边宣称换新脸，一边继续引用被拒脸保形 |

同角色独立正脸的身份引用与跨人物借用旧生成脸分开处理。衣服／身材比例修订必须是参考约束下的新图生成，不能把已交付资产板传成编辑目标。独立正脸获认可，或被用户明确指定继续后，才作对应角色的身份基准；助手自评和较新的失败版本不能替代用户认可。背景、排版、肤质等其他修订不自动套用衣服流程，但须服从用户当次指令。

用户叫停、只讨论、只改技能或只存档时不调用生成工具，包括所谓测试图。既有编辑授权无需重复询问；尚未定脸时只确认具体面孔，不让用户重新回答背景、服装或审批长提示词。

## 2. 生成前写可检验的结构设计记录

先选外部样本，再确定整体脸部体量与年龄，最后协调局部。记录保持简短，但每项能对应到实际像素：

1. **来源与取舍**：写明实际看过的样本、可见关系、采用部分和协调调整；区分表情、镜头、妆造的影响。只有链接清单或模糊的“自然感”不算完成。
2. **主导关系**：选择本人的两三个相容结构关系。至少覆盖眉眼与其周围组织，并联到脸部体量或鼻唇下颌；不能把眼、鼻、嘴分别理想化再拼合。写相对关系，不从低清图编造毫米数或固定比例。
3. **可见预期**：对每个主导关系，说明正常看整脸时应看到什么，再说明必要时看哪个局部。只在极小裁切里勉强找出的不对称不能充当整脸辨识度。
4. **神态关系**：注视落点、眼睑张力与眉、面颊、嘴角怎样连贯；主正脸仍头正、双眼自然睁开。故事感不自动等于疲惫或悲伤。
5. **本次退回条件**：预先写出哪些变化会毁掉这张脸的设计，例如某个关键体量被收掉、上下睑关系被替换、鼻唇与下庭失去原定联系。必须针对这张脸，不把某种圆眼、双眼皮、窄鼻或尖下巴普遍判为AI。

实际生成提示词由这些关系组织，主体优先，衣服、肤质和版式随后。删掉会把所有器官一同理想化的相互冲突描述；不要固定改成小眼、宽鼻、歪嘴或同一组瑕疵。没有结构设计时，增加“不要AI脸”不构成补救。

男性人物及“太正经／越改越精修”纠偏，按[自然状态流程](male-natural-presence.md)增加整体发型、目光联动、细节保护和退回条件。先审查实际输入方式，外部选材同时覆盖整头与整脸神态，不能只从器官结构推定生活感。

## 3. 选择生成范围，避免整版掩盖长相

- 设计清楚、没有本任务模板脸失败，且未处于已有同类反馈的纠偏过程时，可以直接生成用户要的资产板，随后严格验脸；不为每个普通任务强加一轮试图。下一条触发条件成立时优先转正脸候选。
- 已有用户指出的模板脸问题、正在处理本用户反复出现的同类问题，或整版让主导关系难以判读时，先生成一张清晰正脸候选。暂不混入三视图、复杂服装展示和多种动作；候选服装与背景仍服从本次选择。
- 正脸候选只作阶段交付。需要定脸时确认这张具体的脸；一旦获认可，后续扩板使用该图作为同角色身份参考，不能再走纯文字重抽。用户没有要求扩板或已叫停时不自动继续。
- 单张场景写真按其构图目的执行；脸部遮挡或侧转使结构无法验收时说明可判断范围，不强改成资产板。

缩小生成范围用于隔离并检查人脸问题，不宣称这种方法必定消除模板脸。

## 4. 先验脸，再验衣服和皮肤

按生成前记录逐项留下短评：**设计关系 → 当前像素 → 通过／不通过／无法判断**。

- 先以正常观看尺寸看完整头部和整脸的发型组织、视线与神态；再暂时忽略发型、衣服、妆容和皮肤纹理核对五官主导关系，最后按需要查看眉眼、鼻唇和轮廓裁切。两层都要成立，不能只在裁切里找出毛孔或不对称便判整脸自然。新人物只与本次设计和实际外部观察核对，不打开历史生成图库比较。
- 主导关系必须实际可见，且共同构成一个协调、有神态的人。若关键关系消失、多个部位一起被重新理想化，或只有毛孔、痣与睑褶轻微变化，不能判通过。漂亮本身不证明模板化，粗糙或不对称也不证明有特色。
- “无法判断”不得写成通过。小脸、遮挡或清晰度不足时解决可见性，不能靠提示词承诺。用户已经否定的长相优先于助手原来的自评。
- 脸部通过后才核对衣服、手、头脚、三视图和背景；衣服不合格不能作为重设已成立长相的理由。

**失败后的动作必须改变关键变量。** 首次确认整版长相失败，停止同提示词整版重抽，回到外部样本重选或重组未落实的主导关系，转单正脸候选；不能只换修饰词或加瑕疵。连续两张正脸候选仍不合格时停止自动重试，报告未落实的关系和需要改变的输入或方式。用户叫停立即停止，不为满足次数继续。

若连续纯文字候选未落实结构或仍太端正，优先准备能支持缺口的外部结构／状态图像参考方案；按[输入分流](male-natural-presence.md#3-用输入方式解决已确认的失败)核对当次授权后再继续。准备来源不等于调用生成；改技能或既往其他角色授权不解除叫停，也不重置失败计数。

## 5. 同任务换装与身材比例：引用定脸重新生成

资产图交付后的入口与原句由[主技能](../SKILL.md#交付后的换装身材比例选项)统一规定。用户提供服装参考／描述或目标身高后再执行；只点击入口但没有给信息时，简短索取缺少的参考或身高，不自行选择一套新衣或一个身高。

先记录：**认可的独立正脸路径／用户认可范围／本次服装或身高要求／必须保留的条件**。认可第一张脸而否定第二张时选第一张，不按“最近一张”选基准。若正确独立正脸不可用，先定位找回；不把完整旧资产板临时改名为身份参考或随机重抽脸。

生成顺序：

1. 查看正确独立正脸，作为本角色唯一身份参考；不把旧资产图当底图、画布、编辑目标或最近图片输入。旧资产图只可供本任务结果核对，不送入该次生成替代独立正脸。
2. 服装图用于提取穿搭；需要实际输入时明确它只提供服装和配件，排除模特的脸、发型、体态、场景及画质。不得用衣服照片的模特替换已认可人物。
3. 目标身高写为当前人物的裸足身高设定，统筹头身、肩胯、躯干、臂长、大小腿、膝位与手脚尺度；帽子和鞋底另计。衣摆、裙摆和袜口随正确身体位置安排。身高不能仅靠拉长小腿、缩短躯干、厚底鞋或低机位假造；没有标尺不声称厘米实测。168cm及任何固定头身数都不是后续人物默认。
4. 发出完整新图生成请求：引用已认可正脸，按新服装／比例从头构建同一人物资产图，保持未变更的背景、发型、配件、版式和张数。只有衣服变化时保留既有身体设定；只有身高／比例变化时保留既有套装。不要重新设计眉眼鼻唇，不用纯文字碰运气重抽长相。
5. **整个流程禁止把图片当底图修改。** 不调用旧资产图的蒙版修补、局部重绘、涂抹、图像拉伸、衣服贴回或换脸补救；不在失败再生图上继续叠加修改。图像作为独立身份或服装参考不等于编辑底图，必须如实记录实际传入文件与分工。
6. 新图先对照已认可正脸验收长相，再核对服装、体态比例、全身完整性和所有视图连续性。衣服／比例改好了但脸漂移，整次仍不通过；下次仍从正确独立正脸及原条件重新生成，不把失败成图作底图。一次针对性纠正仍无法保住脸时停止自动重试并说明具体限制。

每轮保留旧交付、保存本次新原图、实际提示词和输入链，不覆盖旧文件。完整资产图交付后再次显示可选入口，但不自动开启下一轮。重新生成不承诺任何尺度下绝对无噪点或像素绝对不变，仍检查真实像素。只有用户明确改要独立照片时才改变原资产板形式。

## 6. 保存与验证范围

保存结构设计记录、实际参考输入、版本路径、验收短评和用户原话范围。服装／身高修订保留独立身份参考与新生成原文件，不让失败版或旧整版成为下一次底图；引用的同角色正脸不进入其他新人物素材库。技能案例仍需“存档”或直接技能更新授权，当前图片不自动归档。

本次仅修改技能和检查规则分流，未生成测试图。因此只能报告执行规则、引用关系和静态校验已改，不能宣称实际出图已稳定消除模板脸或保形已经实测成功。
