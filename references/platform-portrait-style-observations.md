## 把风格变成能执行的取景选择

以下为结合用户反馈与实际样本形成的创作方案，不是“一个平台一种风格”的分类，也不是每次都要加入的固定效果。

| 表达方向 | 提示词应交代的实际关系 | 易出现的生成偏差 |
| --- | --- | --- |
| 朋友随手拍的日常人像 | 相机与人物的距离、朋友站在哪里、人物正在做的一个动作；脸可读，背景有生活信息；按需要裁到腰或大腿 | 全身笔直站定、手没有用途；人远到看不清神态；用全背景虚化掩盖空间 |
| 安静或疏离的情绪人像 | 目光落点、眼睑与嘴部松紧、一处有动机的光影；衣料、天气和姿态相容 | 把情绪全写成空洞目光、统一瘦削苍白；堆灯牌和逆光却没有可读的脸 |
| 活力与镜头互动 | 一个正在进行的身体动作，肩线与头部方向错开，近远层次合理，必要时容许轻微运动痕迹 | 所有人跳跃、夸张仰拍或故意模糊；用动作替代具体人物性格 |
| 复古直闪或胶片表达 | 先选一种主要光线逻辑，再写色彩、明暗与适量颗粒；保留具体脸和真实体积 | 同时堆柔光、硬直闪、重雾与电影光；加颗粒却仍是标准美化脸 |
| 穿搭与都市街景 | 全身时让轮廓、衣料与鞋可读；半身时强调脸和上装；建筑线条引导主体，手靠栏杆或持物有支撑 | 把腿无限拉长、机位过低扭曲头身；所有图都要求鞋与完整建筑入镜 |
| 多人生活与家庭记录 | 先定人与人的关系和动作，再安排每个人的位置、视线和遮挡；年龄、体态各有依据 | 大家同时看镜头、同一种笑；把年长者统一憔悴或把幼儿做成玩偶 |

社交平台照片也可能有精心设计或修饰。“随手拍感”是画面表达，不能据此断言作品真的未摆拍、未修图。漂亮、有妆造、有设计感，也可以有个人特点；日常感不要求故意做脏、做丑、加噪点或把画面拍糊。

## 生成前的实际决策

1. 先确定这次要的是人与镜头交流、情绪、穿搭、地点，还是多人关系。通常选择一个主方向；从用户认可的参考判断，不要求用户在风格名词中重新作答。
2. 写清画幅、拍摄者位置、相机高度、距离、人物大小与裁切，再写动作、视线、光线和场景。比例数字仅在构图需要时辅助，不把所有人都固定在同一格线。
3. 一张照片只需要一个可信的当下。例如同行中回头回应：行走方向、头部转向、肩线与视线相互配合，手持物有实际支撑；让各部位属于同一瞬间。
4. 五官仍按主技能设计相容的个体结构。拍法、妆造、胶片色彩与真实脸部结构分别考虑；不以平台上常见的修饰效果作为五官模板，不擅自照搬样本人物。
5. 用普通手机观看尺寸检查：先看到什么、脸与动作能否读懂、背景是否抢走主体、肢体是否有支撑。再检查小范围肤质，避免用细节纹理掩盖整体塑料感。

本记录只保留通用调研与方法，不写入单次图片任务的具体设定。当前平台样本仍偏年轻女性，不能声明已覆盖三平台各年龄与性别的全部主流审美；效果由后续实际成图和用户评价检验。
