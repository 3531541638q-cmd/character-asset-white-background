# 男性人物的自然状态：来源、输入与细节保护

适用：设计男性人物，或用户指出“太正经、过于端正、发型和眼神太标准、越改越精修”。2026-10-27用户要求实现本流程；修正的是选材、输入和验收方法，不把某种男性外貌设成默认。其他人物出现同类问题时也可按问题选用。身份、换装与重新生成边界仍按[设计与保形流程](face-design-and-identity-preservation.md)。

用户的校准是：“不完美不是故意丑化”，需要“细节中些许的不完美才贴合现实中的人”。人物可以好看；自然差异、吸引力和整体协调一起成立。不能通过统一缩眼、歪嘴、添疤、加重疲惫或蓬乱头发来交差。

## 1. 先核对实际输入，避免归错原因

记录两件不同的事：**实际看过哪些外部图片**，以及**生成工具实际收到哪些图片与分工**。纯文字从照片观察取材，仍是纯文字生成；已获授权并实际传入结构／发型／状态图，才是图像参考生成。不能把“看过图”说成“用了图像输入”，也不能因为提示词写了参考就声称结构已传入。

本聊天中，用户采用的两张女性正脸使用了外部局部结构图像输入；两张未采用的男性候选均为纯文字。第二张男性尝试放松发型和表情后，用户指出更端正、很多细节被修掉。这个记录支持改变当前方法，不足以证明生成模型天然更擅长女性或只需增加男性瑕疵。两张男性候选不作后续身份、设计或审图模板，不加入认可案例；修改技能不等于恢复生成授权。

## 2. 选材必须覆盖整头与连贯神态

先按[男性自拍素材索引](research-2026-10-28/xhs-male-selfies/index.md)检索本次需要的脸部体量、整头发型和神态，实际开图后选用；旧三张不再作为默认组合。按当前缺口补充其他已有或公开来源；不让用户承担常规找图。使用样本前看真实像素，记录来源、可见范围、采用关系与限制。不要只因性别相符就套用浓眉、宽颌、高鼻、冷淡直视和蓬松中分这一整套组合。

| 本次需要支持的内容 | 选看什么 | 不足以支持什么 |
| --- | --- | --- |
| 五官与面部体量 | 眼睑、眉下空间、颊部、鼻唇下庭在同一张脸里的尺度与衔接 | 只见眼睛的裁切不能决定整脸体量；俯拍、眯眼或手托脸不直接编码成永久不对称 |
| 整体发型 | 可见头顶、两侧、分缝或发根走向、刘海落点及其与头形的关系 | 几根飞丝不能证明发型自然；沙龙造型和过度整理图不作为生活发型的唯一依据 |
| 目光与表情 | 注视落点、上下睑张力，以及眉、面颊、嘴角怎样一起响应 | 单眼局部或空泛“松弛”不足以推断整脸神态；瞪眼、歪头不能代替情绪 |
| 局部细节 | 眼睑边缘及厚度、眼下过渡、鼻翼至面颊转折、唇缝与口角、中间调 | 低清、强滤镜、过曝或大面积遮挡不能作细节证据；不声称照片未经修饰 |

这些是覆盖关系，不规定必须几张或固定使用哪位人物。一个来源可支持多个方面；若只有器官裁切，补看整头和整脸状态。小图可供宽泛造型观察，不能编造眼睑、唇缘和微表情。按脸宽、年龄与表达协调采用的关系，不机械拼整脸，也不把同一套来源组合固定用在每个男性身上。

### 发型多样性与快速选材

按[本轮发型、五官与穿搭索引](research-2026-10-28/male-hair-face-style/index.md)实际查看适配样本。先确定是否露额、刘海厚薄与长度、顶区高低、两侧贴合、耳周和后颈轮廓及直曲密度，再决定有无分缝；三七分不是默认，其他发型也不随机轮换。图像中看不见头顶或后颈时不补写成观察事实。自然感不固定等于乱发或疲惫，发型不绑定固定五官、职业或穿搭；同角色续作不借这条擅改已认可发型。

调研优先批量看照片，只有需要精读或核实的样本再放大、展开或读出处，减少逐帖评论、重复截屏及无关操作。完整原图和来源记录支持后续查用；排除、修饰、拼图及遮挡限制按逐条记录执行。这是研究效率要求，不替代必要的生成确认和视觉验收。

## 3. 用输入方式解决已确认的失败

普通新照片任务仍遵守[默认照片流程](../SKILL.md#01-有照片时先反推提示词再用文字生成新人物)，先反推、默认纯文字设计新人物；不因为调用本模块就自动上传真人照片。

已有“过于端正／精修”失败时，先找出未落实的是结构、整体发型、神态还是细节保护，准备能支持这些关系的外部图。**连续两张正脸候选失败后停止自动重试**，不能再换“随意、松弛、自然”的形容词进行第三次纯文字盲抽。用户明确要继续时，优先提出实际外部结构／状态图像输入的改法；当次已明确授权该用途就执行，不重复征求许可。尚无此授权时，先把来源、可用部分和输入分工准备具体，再一次说明为什么需要以及哪几张图将传入，等用户回答后执行。既往女性任务的引用授权不扩展到这位男性。

实际传图时，将结构、发型组织、神态各自作用写清楚；状态参考只借用眼睑与眉颊口周的联动方式，调整到新人物，不复制完整身份或强制复刻原表情。只含眼部的图不能冒称整头发型参考；未批准的旧生成脸不能换名成状态参考。工具不支持这样的参考用途或找不到可读来源时，报告具体缺口，不声称图像输入已生效。

需要用户帮助时说明：**缺哪类可见信息／哪张来源无法访问／需要允许哪种输入 → 会怎样用于本人物 → 现有材料为什么不足**。例如确实找不到可见发根与两侧的合适生活发型时，再请求一张此类参考。已确定的白底、服装及其他条件不重问；没有实质缺口就继续准备。只改技能、只讨论或叫停时不出测试图。

## 4. 设计记录增加四个相互独立的字段

保留原有两三个主导结构关系，另用短句落实下列内容；这是设计字段，不是每人必备的缺点清单。

- **整体发型组织**：结合实际样本写头顶与两侧体量、分缝、发根贴合及发束走向怎样形成一个人的日常发型。先看大轮廓是否被整理成平衡完整的弧，再看细发；不为“自然”统一偏分、压扁一侧或弄乱头发。
- **具体注视与表情联动**：资产正脸看向镜头附近的拍摄者，按本人物确定平静关注、轻微迟疑或正在回应等状态，并写可见的睑、眉、颊、嘴角关系；这些仅是选项，不整段反复套用。头正、睁眼、看清五官是几何要求，不要求空白表情、严肃凝视、左右肌肉完全一致；不靠歪头、转侧或玻璃珠大瞳孔制造灵气。
- **需要保留的细节层次**：选本次确实可见或另行设计的眼睑厚薄与褶皱转折、鼻翼和面颊的体积衔接、唇缝唇缘与口角、局部肤色中间调。它们区别于毛孔和飞丝，不能用“有毛孔”证明未精修。新人物的依据来自外部观察与本次设计；已认可同角色则对照正确独立正脸，不用失败稿锁定长相。
- **本次退回条件**：把上述关系写成正常尺寸能检验的预期，例如发型仍是成对完整圆弧、目光被统一放大提亮、嘴角与颊部毫无响应、唇缘和眼下体积被磨平。依据本次人物定条件，不把任意一种眼型或整齐发型普遍判错。

实际提示词先写五官关系、整体发型和神态，再写局部细节、摄影与背景；删去会互相抵消的“无瑕、每处精致、完美对称、商业精修”要求。仅变更发型和神态时，别同时下达全脸变得更平整、更年轻、更亮、更大眼的修正。皮肤控制按[局部与整体平滑模块](research-2026-10-27/skin-and-smooth-prompt-module.md)，完整控制句保留，但不允许它覆盖眼睑、唇缘和面部中间调。

## 5. 验收先看整体状态，再看结构和细节

先在正常观看尺寸看完整头部与整脸：发型大轮廓、视线及表情是否仍像统一整理的展示照；随后暂时忽略头发与皮肤纹理核对五官主导关系，再看必要裁切中的细节层次。不能只放大找几个缺点来证明整脸自然。

逐项记录“设计关系 → 实际像素 → 通过／不通过／无法判断”，分别检查：

- 整体发束是否仍被梳成过分完整的体块；多几根飞丝不能抵消这个问题。
- 眼神与眉颊口周是否连贯；歪头、半眯、强反光或空白中性凝视不能当作已经放松。
- 眼睑、鼻翼、唇缘和颊颌的细小体积与颜色过渡是否仍存在；毛孔变多但这些层次消失，仍是过度整理。
- 资产主正脸是否头正、双眼自然睁开、朝向镜头、无遮挡；神态自然不能抵消几何不合格，几何合格也不能抵消神态失败。
- 本次采用的关系是否共同形成好看、协调、有个人特点的人；故意丑化或夸张不对称同样不通过。

新人物只核对外部观察与本次设计，不加载历史生成图库求差异。已认可角色续作则先对照正确独立正脸，再检查上述细节是否流失。用户否定优先于助手原先自评；失败时记录具体未落实处，按[失败边界](face-design-and-identity-preservation.md#4-先验脸再验衣服和皮肤)停止或改变方法，不能重置失败计数继续盲抽。换装／比例仍引用认可正脸重新生成，禁止旧资产板底图修改。

该流程修订尚未经过新出图验证；静态校验、提示词写过或换了输入方式均不等于已解决自然感。正脸未获采用不得自动扩板，也不得记成认可案例。
