# 全身小脸遮挡、高清与人工噪点：上下文和执行

记录日期：2026-11-06。用户明确要求：“更新skill，把有用信息记录进skill。关于盖住全身视图，高清，不生成噪点的上下文是要记录的”。本记录补充已存在的遮挡与肤质要求，不移除旧档案，不生成测试图。

## 为什么全身脸要盖住

早前人物资产反馈：“重新生成，全身视图的脸挡住，防止生成视频脸扭曲”。本轮展开睡衣资产板时再次明确：“全身视图脸盖住，防止生成脸部漂移”。用途是将信息分工：正侧背提供服装、身材和发型，大幅正脸提供明确的五官参考，避免把低像素或不同视角的小脸也作为后续视频的脸部依据。用户没有要求隐藏主正脸。

后续本用户的人物资产板主动沿用这一已选方案，不反复询问是否遮脸；新指令要求展示三视图五官时按当次要求。它不把独立写真、场景照或所有人物图片变成遮脸图。

- 正面、侧面和其他露脸的全身小图，用一整块实心、不透明、哑灰色的脸形遮挡覆盖额头眉眼、面颊、鼻、口、下巴；侧面还要包住鼻尖、嘴唇和下巴突出的前缘。
- 灰块是图上的遮挡，不生成有绑带的实体面具。不能只盖眼睛、戴墨镜、透明虚化、马赛克或留下鼻口碎片。
- 保留头发、发型轮廓及服装可见性；不把灰块扩散到后脑、衣领。真正背面没有脸，不遮后脑。
- 大幅主正脸及眼部细节保持清晰，仍须头正、眼睛自然睁开、平视、脸部面积足够。
- 定脸扩板、换装和比例修订均保留此分工。身份只引用当前角色认可的独立正脸；扩板时不再叠加真人研究图或失败脸来重设计身份。

验收先看布局和主脸，再查灰块范围；被盖住的五官无法判读，不宣称“小脸与大脸逐一验过一致”。可检查发型、体型、衣服连续性。遮脸是用户指定的制作策略，本轮没有生成/测试视频，不能称漂移已实测消除或保证绝不扭曲。

## “高清、不要GPT独有噪点”的含义

早前原话包括：“可以，重新生成，禁止gpt独有的噪点。需要高清”“ok，重新生成，稍微给他一点妆容。高清，并且不要有gpt独有的噪点。握刀在合理位置”。用户要求画面清楚干净，细节服从人物和物件形体；不是要求通过加密毛孔或锐化把图做得看起来很忙，也不是把真人皮肤磨成塑料。

这项要求按人物资产交付持续执行。轻妆、刀型、握刀等属于当时具体角色，不成为睡衣人物或其他角色的默认。

- 提示词先写五官结构、姿态、衣服和物件，再控制细节密度；加入干净背景、自然中间调、清楚边缘、避免人工重复噪纹。保留[肤质模块](research-2026-10-27/skin-and-smooth-prompt-module.md)的完整平滑控制句，解释其用于全局组织。
- 不机械堆“毛孔、汗毛、瑕疵、旧化”。局部自然肤质与眼睑厚度、鼻翼至面颊转折、唇缘、指关节和材料褶皱应能区分。重复旋纹、砂纸纹、随机亮暗点、全图颗粒和锐化光晕不是这些结构。
- 先在正常观看尺寸验人物与整体干净程度，再看原生像素的眼鼻颊、手、衣料、白底和哑灰遮挡区。不以极小局部有毛孔证明整张自然，不以全脸抛光代替去人工噪点。
- 若发现人工纹理问题，在用户授权的质量修订范围内处理并复看实际结果，保住认可脸和解剖。质量修订不授权借机改变衣服/身材；这两者仍引用正确独立正脸生成新板，禁止旧板底图编辑。
- 请求工具支持的高清输出；不虚构它没有的尺寸选项，不为了取尺寸擅换外部付费平台。交付前读取真实像素，明确原生输出与后期放大。普通插值或锐化不能冒称原生4K；文件可读、哈希相同只验证文件，不证明视觉质量。
- 不作任意放大下绝对零噪点的承诺，描述实际看过的区域和未验证范围。没有新图时不能把修改提示词、写文档或文件校验说成已出高清图。
