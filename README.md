# 你健哥的人物资产生成器

将人物描述或参考照片反推的文字提示词，转成具有个人长相特色与真实生活感的人物资产。

- 出图前确认背景和服装处理方式，按当前任务选择全身正侧背、清晰正脸特写及细节视图。
- 默认从照片提取观察，再以文字设计原创人物；保留本人和图像参考按用户当次要求处理。
- 新人物设计与同一角色换装、身材比例调整分别处理，保留已认可人物的长相。
- 全身视图小脸完整遮挡，大幅正脸和眼部细节保持清晰，服务后续视频人物参考。
- 高清交付如实报告原生尺寸；检查人工颗粒、重复旋纹等噪点，同时保留真实五官和局部肤质层次。
- 附带五官、发型、穿搭、年龄、体态、肤质和构图等参考文档与调研素材。

技能入口：[SKILL.md](SKILL.md)。技能标识：`character-asset-white-background`。
